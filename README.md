# auto-updater

o launcher compara a versão instalada com a versão publicada no GitHub Releases.

se tiver atualização, baixa o pacote, confere os arquivos e aplica. só registra a versão nova quando termina certo.

os pacotes são cumulativos, então quem pulou versões pode ir direto pra atual. as configurações pessoais ficam preservadas.

quando o próprio launcher precisa atualizar, ele fecha, um auxiliar troca os arquivos e abre de novo.
